## Description

A RAII wrapper for C file handler (`std::FILE*`).

## Build

Build the application using Bazel:

```
bazel build //assessment-3-2/src:main
```

Then you can launch it by running:

```
./bazel-bin/assessment-3-2/src/main
```

Alternatively, build and run by using the following command:

```
bazel run //assessment-3-2/src:main
```
